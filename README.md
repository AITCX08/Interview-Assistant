# Interview Assistant · 面试助手

实时捕获腾讯会议、钉钉等视频会议软件的系统音频，使用本地 **FunASR Paraformer** 模型将语音转为文字，并通过置顶浮窗实时展示，支持一键复制到历史记录。

---

## 功能特性

| 功能 | 说明 |
|------|------|
| 🎙 实时语音识别 | 监听系统音频，段落结束后自动转文字 |
| 📋 复制到历史 | 点击按钮，当前内容带时间戳追加到历史区，同时写入剪贴板 |
| 🗑 删除 | 清空当前识别区 |
| 🪟 窗口置顶 | 浮窗默认置顶，随时可见 |
| 🌐 多语言 | 支持中文、英文及自动检测 |
| 💻 本地语音识别 | FunASR Paraformer 本地推理，首次下载模型需联网 |
| 🤖 DeepSeek 建议 | GUI 配置 Key，支持手动或识别后自动生成流式建议 |
| ⏱ 延迟与模拟 | 显示识别排队/推理、AI 首字/完成耗时，支持不联网的本地模拟 |

## 配置会议软件音频捕获

### Linux（推荐）
在「音频设备」下拉框中选择带 **`[系统音频]`** 前缀的设备（PulseAudio/PipeWire monitor），即可捕获腾讯会议、钉钉等软件播放的声音。

### Windows（推荐：VB-CABLE）

**Step 1 — 安装 VB-CABLE 驱动**
下载并以管理员身份运行 `VBCABLE_Driver_Pack45.exe`：
https://vb-audio.com/Cable/

安装完成后系统会新增两个虚拟设备：
- `CABLE Input` — 虚拟扬声器（让会议软件往这里输出）
- `CABLE Output` — 虚拟麦克风（本工具从这里读取）

**Step 2 — 设置会议软件扬声器**
打开腾讯会议 / 钉钉 / Zoom 等，将「扬声器」改为 **CABLE Input**。

**Step 3 — 启动本工具**
运行 `python main.py`，「音频设备」下拉框会自动选中 **`[VB-CABLE] CABLE Output`**，直接点「开始监听」即可。

---

> ⚠️ **使用 CABLE Input 作为扬声器后没有声音？**
>
> 这是因为音频流进了虚拟管道，没有转发到真实扬声器。解决方法：
>
> 1. 右键任务栏音量图标 → **声音**（或打开控制面板 → 声音）
> 2. 切到 **录制** 选项卡
> 3. 找到 **CABLE Output** → 右键 → **属性**
> 4. 切到 **侦听** 标签页
> 5. 勾选 **侦听此设备**
> 6. 「通过此设备播放」选你的 **真实耳机 / 扬声器**
> 7. 点击 **确定**
>
> 设置完成后，音频会同时送到：CABLE Output（本工具识别）+ 你的真实扬声器（你能听到）。

### macOS
安装 [BlackHole](https://github.com/ExistentialAudio/BlackHole) 虚拟音频设备，并在会议软件中将输出路由到 BlackHole，再在本工具中选择 BlackHole 作为输入设备。

## 常见问题

**Q: 识别延迟多久？**
A: 默认在约 1.2 秒静音后提交语音段；可以在界面调整阈值和静音时长。推理耗时取决于模型、设备和音频长度，尚未提供标准性能基准。

**Q: 支持英文吗？**
A: 支持。在语言下拉框选 `en` 自动切换为 `paraformer-en`，选 `auto` 使用 SenseVoice 多语言模型。

**Q: 首次下载慢怎么办？**
A: 首次加载通过模型库下载并缓存。请检查网络与模型缓存；是否能完全离线加载，需要在具体依赖版本和模型组合上验证。

**Q: 识别效果有基准测试吗？**
A: 当前项目没有发布统一测试集上的字错率或模型对比结果，效果需要结合实际音频验证。

## DeepSeek 配置与自动建议

1. 打开“DeepSeek 建议与配置”页，填写 API Key，选择模型与回答长度，然后点击“应用配置”。Key 默认遮罩显示；勾选“本机加密记住 Key”后通过 Windows DPAPI 保存，未勾选时本次填写仅保留内存。
2. 点击“生成建议”发送当前转写区文字；勾选“识别完成后自动生成建议”启用自动回答。默认开启本地中文问题判定，跳过确认语、合并未完的问题、短时间去重；不自动上传历史或音频。关闭“仅完整问题自动回答”可恢复逐段触发。
3. 回答逐块显示；新问题会替换旧问题，按钮“取消回答”可使旧结果失效。取消不保证撤回服务端已发生的计费；网络阻塞可能使最新请求等待旧请求超时。
4. 点击“本地模拟（不联网）”可在没有 Key 的情况下验证回答区和耗时显示；模拟结果会明确标注。

点击“低延迟停顿：0.6 秒”后在下一次开始监听时应用该设置，当前默认停顿为 0.6 秒。中文可勾选“中文流式识别”并点击“重新加载模型”，使用独立的 Paraformer 流式模型在说话中持续识别。中间文字仅显示，结束语句才进行自动回答判定。默认仍为整句模式，较短停顿可能拆句。架构、实测及限制见 [性能报告](docs/performance.md)。

语音转写可本地进行；DeepSeek 功能需要联网，并可能产生接口费用。填写或应用 Key 本身不会发起网络请求。

## 隐私与许可证

音频采集应在参与者同意且符合会议或面试规则的场景下使用。识别文本会显示在窗口中；点击复制按钮会写入系统剪贴板。请勿将真实录音、会议文本或凭据提交到仓库。

本项目采用 [MIT 许可证](LICENSE)。使用、修改和分发时请保留版权及许可证声明。第三方依赖和模型分别遵循各自的许可证。


### 本地简历上下文与凭据

“简历上下文（本地）”页可导入 PDF/DOCX，解析后预览可编辑。常见电话、邮箱、标注姓名与链接会被替换；其他身份线索须手动检查，自动处理不保证完整匿名。默认不携带简历，勾选后每次真实回答会向 DeepSeek 发送编辑后的上下文文字，不上传原文件。扫描 PDF 暂不支持 OCR；文档限 10 MB、PDF 20 页、上下文 12000 字符。

简历与提取文本仅保存在运行内存。清空或编辑上下文会取消当前回答。PDF/DOCX、上传目录和本地验证产物已加入 Git 忽略规则，公开提交前仍应检查暂存区，避免强制添加私有文件。

Windows 可勾选“本机加密记住 Key”并应用配置，凭据通过当前 Windows 用户的 DPAPI 加密存于 `%LOCALAPPDATA%/InterviewAssistant/deepseek-key.dpapi`，启动时自动回读。取消勾选只控制本次应用是否保存，不会删除此前保存的 Key。该方式不防范已能访问当前用户会话的程序。

DeepSeek 接口无状态，本功能会在每次请求携带已启用的简历背景；目前不自动携带历次 AI 问答。上下文缓存由服务端尽力命中，不能当作永久记忆。“本地模拟”不联网，不验证真实 Key 或云端性能。


### 低延迟配置

GUI 默认停顿为 0.6 秒；长思考停顿可能拆句，必要时调回 1.2 秒。FunASR 1.3.1 的中文/英文路径默认尝试复用已审查的只读模型资源，同时每次隔离可变缓存；其他版本自动走兼容模式。取消“复用模型资源”并重载模型可回到原配置复制行为。真实 VB-CABLE 的本机速度与测试限制见 [性能说明](docs/performance.md)，不能据此保证不同机器的延迟。

流式模式目前仅支持中文选项，首次加载会下载官方模型到本机缓存，不会写进仓库。每个语句使用独立缓存；队列积压或输入溢出会丢弃当前语句并提示，防止拼接不连续音频。停止监听、取消回答和切换模式会清空待答问题。本地规则无法完全理解语义，漏判时可以手动生成建议或关闭问题判定。
