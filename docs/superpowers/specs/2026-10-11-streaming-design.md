# 流式识别与中文问题判定

用户已批准执行研究建议中的第一阶段。保留整句识别作为默认对照，新增中文流式模式和界面开关；采用官方 Paraformer 流式模型、600 毫秒输入块、单线程顺序推理、每个语句独立缓存。中间文字仅显示，结束语句才提交自动回答判定。

中文判定在本地跳过确认语、合并未完成句子，并限制等待时间和缓冲长度。等待期间不发起模型请求；停止监听、切换模型和关闭窗口清空待答状态。手动回答不受过滤影响。

队列溢出不能拼接有缺口的缓存：使当前语句失效，清理缓存，并等待下一语句。暂停与重启隔离旧推理结果。流式失败明确显示错误，用户可切回整句模式。

验证采用合成问题、假模型边界测试及真实本地模型实时音频对照；可复用已授权的 VB-CABLE 与 DeepSeek 合成问题测试，不加载私人简历。模型权重下载到本机缓存，不进入 Git。只有实际对照更优才考虑修改默认模式。
